# KYO v22.5

Cambios:
- Rewards: 1 punto por cada $10 de subtotal al marcar el pedido como entregado.
  Ejemplos:
  - $99 -> 9 puntos
  - $100 -> 10 puntos
  - $257 -> 25 puntos
- El sello del reto de 6 pedidos sigue sumando 1 por pedido entregado.
- Panel > Configuración permite agregar puntos manualmente a un usuario por correo.
- Los avisos verdes de Preferencias ahora son compactos.

Ejecuta una sola vez:
supabase/migrate-v22-5-points.sql
