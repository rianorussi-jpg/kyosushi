# KYO v22 — Charcoal / Gray / Orange

Rediseño visual sobre la v20/v21 sin cambios al backend.

Cambios principales:
- Paleta negro carbón, grafito, grises y naranja.
- Header idéntico en Inicio, Menú, Rewards, Pedidos y Perfil.
- Logo siempre a la izquierda.
- Dirección / pickup siempre a la derecha.
- Home reconstruido con composición distinta y más de app final.
- Menú oscuro, categorías más compactas y tarjetas más modernas.
- Rewards, Pedidos, Perfil, Carrito, Checkout, Login y Success alineados a la misma identidad.
- Panel y Modo Cocina también refinados visualmente.

No requiere SQL nuevo respecto a v20.
